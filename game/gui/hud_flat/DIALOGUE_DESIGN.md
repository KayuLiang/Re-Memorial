# 对话框：纸页与功能页签

本轮只调整对白组件；不修改其他 HUD、剧情文本、时间规则或存档行为。
参考来源：用户选定的 SEASON 纸页、Dordogne 页签，以及用户提供的素描图标截图。
参考游戏图片不进入发行素材；五个对白功能图标恢复为 Phosphor 库图标占位。用户已否定程序化自绘笔触，将亲自使用 PS 插件、效果或笔刷制作最终图标；后续仅接入用户素材、处理尺寸和对齐。

## 为什么这样排

以 1920×1080 游戏画布为准，保持既有姓名、正文与人物照片的位置。

| 部分 | 实现尺寸与位置 | 设计理由 |
| --- | --- | --- |
| 功能页签 | 从左到右：历史、隐藏 UI、自动、快进、设置；72×88 固定点击区，间距 8；x=1448/1528/1608/1688/1768，y=728 | 五项同级、相同尺寸；最右边缘 1840 与继续按钮对齐，距拓宽后的主纸页右边缘 20；动画不移动点击区，避免鼠标进出抖动。 |
| 页签与纸页接合 | 先画页签，后画前景纸页；静止顶端 y=752，悬停 y=728，根部始终被 y=800 起的主纸遮住 | 用真实绘制层级表现“插入纸页”，不再把短矩形叠在纸面上。悬停用 .16 秒伸出 24px，离开 .12 秒收回。 |
| 图标内部 | 48×48 画布置于页签 x+12/y；库图标等比缩入内部 40×40 区域，四边留 4 | 图标中心和视觉大小统一。暂不加手绘效果，供用户重绘时沿用尺寸。 |
| 姓名与正文 | x=288；姓名 38、正文 32；姓名在 56 高的行内垂直居中 | 姓名清晰，长正文保留原阅读宽度；页签不挤进正文。 |
| 纸层 | 素材总宽 1840、高 252；两侧各 20 中，12 是封皮，8 是紧贴的纸页边缘 | 封皮由 32 收窄至 12；主纸左右各拓宽 20。外框总尺寸不变，不多挡人物。 |

## 材质的理由与边界

- 封皮统一为赭色纯色块（#aa824d），去掉深浅分区、斜角块和投影。参考中的颜色差异来自封皮材质，不应解释成明暗光影。
- 纸层压缩到 8 像素窄带，只有紧靠的浅灰纸边和小圆角，取消扇形展开、宽台阶与贯穿侧面的弯曲线。左右使用一致的封皮/纸层关系，正文、照片与页签位置不动。
- 试过在照片下方留白区加淡水痕；实机缩放后更像装饰性笔刷，已删除。当前不加水渍：没有足够好的形状依据，就不为“旧物感”硬加污渍。
- 自绘中心线、随机复描和手写 AUTO 已撤回；不再通过程序重画笔画或模拟笔刷。手绘质感由用户制作，当前库图标不是最终美术。
- 五项采用图标，悬停/键盘焦点伸出后在图标下方显示中文名称；文字稍晚淡入，避免移动中压住图形。保留原生无障碍名称。自动和快进开启时用色差加短下划线表示，不能只靠颜色判断。
- 仅页签图形上下移动，点击框、相邻页签、正文与前景纸页完全不动；没有循环动画。
- 不恢复侧面线圈，不再添加无功能彩色页签，不在正文下铺横线或满页噪点。

## 保留的交互

历史、隐藏 UI、自动、快进、设置仍调用 Ren'Py 原有动作；Esc 菜单与滚轮回退/前进保持不变。
人物照片仍为“照片待绘”占位，不截图裁切立绘。
继续按钮保留右下角，不作为第六个页签。

## 验证范围

运行 Python 测试、Ren'Py lint 和原生 hud_flat 交互测试；检查普通对白、旁白、最长现有正文、悬停、自动选中和隐藏恢复截图。
最终美术观感仍需用户查看游戏截图判断；没有把代码测试通过当作用户认可。
