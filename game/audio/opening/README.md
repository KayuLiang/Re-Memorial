# Opening audio targets

These stable target filenames are optional placeholders for the opening sequence:

- `electrical_burst.ogg`
- `water_drop_primary.ogg`
- `water_drop_soft.ogg`
- `footsteps_urgent.ogg`
- `heavy_impact.ogg`
- `emergency_radio.ogg`
- `wind_gap.ogg`
- `stretcher_wheels.ogg`
- `metal_scrape.ogg`
- `handoff_shout.ogg`
- `isolation_door.ogg`
- `keyboard_fast.ogg`
- `paper_flip.ogg`
- `electronic_low.ogg`

The opening uses a silent fallback: when a target is not loadable, playback is skipped without interrupting the sequence.
