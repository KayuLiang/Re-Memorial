## 已实现

- 每日三餐选择与六轮行动、睡觉决定、最多三轮深夜行动。餐次不消耗行动轮，支持特殊事件回调；轮间夜宵每天最多一次，第三次深夜行动结束后昏迷。
- 时间由核心统一推进；HUD 常规六孔，深夜逐轮增加，最多九孔。
- 起床意志检定沿用选骰界面，1～3 枚并遵守情绪上限，额外骰与沉重附魔也免费。2026-09-20 确认统一曲线：`T=floor(15+1.88*z-0.063*z*z+0.5)`，`z=clamp(正式POW,6,20)-6`。意志6/10/15/20对应目标15/22/27/29；界面与投掷共享目标，范围外取边界值。临时疲劳、加值和加成不改变基础目标，通用情绪难度修正照常。初始平稳双骰总值期望19，72.5%通过率含属性50%所得+3，无起床专属结果减值。更好的骰子养成允许更高通过率，不按玩家骰池动态锁定概率。
- 自愿熬夜后成功正常醒，失败跳过上午一。昏迷后大成功正常醒，困难成功跳过上午一，其余跳过两个上午。晚起仍获得疲劳，只有提前醒才判定新增困意。
- 起床大失败退化只结算一次；没有可用意志骰时按普通失败起床。
- 疲劳：每个熬夜夜晚在次日起床产生一层，每层精力上限 -1；不自然到期，只能按时夜间睡眠清除。取消原独立的次日精力上限惩罚，避免重复扣除。
- 困意：每层意志检定最终结果 -1，不影响属性或基础目标、不随情绪倍率放大。提前醒时按前夜深夜行动轮数分别独立判定50%；三轮且提前醒至少一层（保护前）。不自然到期；普通咖啡和日间休息各清一层，按时睡清空，事件可指定层数。
- 独立隐形计数器：每次实际疲劳获得留一条 day+7 记录，按时睡清状态但不清记录。有效记录达到三条触发疾病并清空计数器，原疲劳状态保留。病期获得疲劳只加病层，不累计新发病记录；康复后重新累计。记录不显示在HUD。
- 深度疲劳初始一层，每层体质临时 -1。获得当天算第一晚，第七晚完整睡眠结算（含大休）后到期；最后一晚熬夜时，先完成起床疲劳结算，再处理疾病到期，期间每次实际疲劳获得加一层，不续期。
- 七晚按时睡觉后康复，无永久扣点，不获得健康作息；康复后重新累计七晚才能获得健康作息。
- 期间再熬夜，则原期限到期时清除临时减值，按疾病总层数永久扣体质；保留既有正式属性零下限，每个实际损失点产生六点退化进度。
- 健康作息（内部沿用 good_routine 字段）：提供精力充沛(+25%精力上限向下取整)、优质睡眠(沿用睡眠Mood恢复加成)。每次熬夜起床抽一次：25%挡新增疲劳/困意且保留，50%挡且消耗，25%不挡且消耗。不挡费用、昏迷、跳轮；不清旧状态。保护失败先消耗再入账，与深度疲劳正常流程互斥。
- 状态分天气、情绪、生理、药物、疾病、日程；训练疲劳、熬夜疲劳、困意分别记录。UI预览和实际投掷共同使用困意修正。
- 旧存档：旧 sleep_fatigue 有效层转困意，不追造新疲劳或隐形记录。旧版已在起床节点的存档缺少晚间行动数，昏迷按三轮、自愿熬夜按一轮兼容；新存档完整保存轮数。
