# 数值存档与回滚检查

2026-09-21。检查范围为角色的属性、成长、骰组、Mood/病程、精力、时间、睡眠与状态计数；数值公式未修改。

## 检查结论

- `RMCharacterState` 的顶层标量由 Ren'Py 原生 `RevertableObject` 管理，Mood、病程强度、精力、日期、轮次、疲劳层数等可正常存档和回滚。
- 正式属性此前已经使用 `RevertableDict`，生命值也已通过真实读档与回滚验证。
- 属性加值、成长进度、训练疲劳、骰池、骰面、附魔、餐次记录、疲劳历史和深度疲劳数据此前由纯 Python 普通容器创建。它们可以写入存档，但原地修改不会进入 Ren'Py 回滚日志，可能在读档重放时重复，或在主动回滚时残留。

## 已修复

- `RMDice` 改为可回滚对象，骰面使用可回滚列表；新增骰、扩面、改单面、减面、附魔及临时附魔年龄均参与回滚。
- 属性值、属性加成、训练进度、成长与退化进度、待领取奖励/惩罚及其计数器均使用可回滚字典；属性加成的内层列表和记录也参与回滚。
- 餐次选择、疲劳历史、旧睡眠疲劳、深度疲劳和待起床信息使用可回滚容器。
- 新角色直接创建正确类型；旧存档在读取后幂等转换，保留已有键、数值、骰子对象身份和骰面内容。
- `rm_ensure_player()` 以及 Ren'Py 的 after-load 回调统一执行旧档转换，避免读取后重放数值语句前仍使用普通容器。

## 验证

- 修复前，游戏内测试稳定复现属性值、成长进度和骰面回滚后残留。
- `numeric_rollback`：3 个 Ren'Py 用例、27 条断言通过，覆盖真实 Save/Load、Rollback 及模拟旧存档转换。
- `health`：4 个用例、22 条断言通过。
- `sleep_cycle`：3 个用例、46 条断言通过。
- `dice_growth`：4 个用例、31 条断言通过。
- 208 项 Python 单元测试通过；Ren'Py lint 通过，仅有项目原有的 `im.Scale` 弃用提醒。

病例快照、HUD 内容等展示缓存每次以新值整体赋给 Ren'Py store，故事里的好感、时钟和手机计数也是顶层 store 标量；这些路径没有同类嵌套原地修改问题。物品栏由 Ren'Py 脚本的 `default []` 创建，使用引擎原生可回滚列表。
